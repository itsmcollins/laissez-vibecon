<product_requirements>
The application aims to integrate Privy for user authentication and enable x402 payments for agent usage, focusing on Telegram interactions.

1.  **Privy Authentication & Wallet Creation**: Users authenticate via Privy, with an embedded crypto wallet (on Base Sepolia) automatically provisioned on first login. This wallet serves as their payment source.
2.  **Telegram-Initiated Account Linking**: Unlinked Telegram users interacting with an agent are prompted to link their account via a dynamic URL. Upon successful Privy authentication on the frontend, their Privy ID and Telegram ID are linked. The linking message includes the agent's name and per-message price.
3.  **x402 Payment for Agents**: The Telegram webhook endpoint handles payment logic internally, not directly protected by x402. For linked users, their Privy wallet (with server-delegated access via session signers) is used to make x402 payments to the agent creator's wallet. If a user has insufficient USDC, they receive a message with a Base Sepolia faucet link and their wallet address. Successful transactions must include a link to the transaction hash on Base Sepolia Etherscan.
4.  **Agent Management**: Authenticated users can create agents with a  field. Agents created by a user utilize their primary Privy wallet for receiving payments. Any linked user can interact with any agent.
5.  **Seamless User Experience**: After linking, a confirmation message is sent to Telegram, followed by background processing of the original query and the agent's response. The original query processing must also pass through the x402 payment flow.
</product_requirements>
